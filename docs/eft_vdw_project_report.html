EFT-vdW Prototype: Status Report

A static project report summarizing the implementation after reframing around issue #1: all-electron reference, PSP-valence RPA baseline, and EFT-core correction diagnostics.

Current stage: prototype Backend: oscillator channels to alpha(i xi) and C6 Headline clean result: Mg q2

1. Project Positioning

This repository implements an EFT-inspired prototype for computing long-range van der Waals response from oscillator-channel data. The central pipeline is: 

Delta_lambda, f_lambda^osc -> alpha(i xi) -> C6 -> E(R) = -C6 / R^6

The long-term goal is a screened EFT-vdW framework where frozen-core or semicore electronic dynamics are explicit response channels, rather than being hidden inside a static pseudopotential. The current repository is not yet a complete screened vdW functional.

2. What Has Been Implemented

Core backend alpha(i xi), C6 integration, -C6/R6 tail, CSV channels
All-electron reference RKS-LDA/PBE + TDDFT for Ne, Ar, Kr, Mg, Ca
PSP-RPA baseline GTH pseudo-atom TDDFT with PySCF and external CP2K data
EFT-core diagnostics Scalar proxy and l=1 dipole Wilson/MO approximation

5. Milestone C/D: EFT-Core Correction Diagnostics

Two diagnostic correction routes have been tested. The scalar proxy has the right sign but is too small. The l=1 dipole Wilson/MO approximation gives physically relevant corrections.

The key comparison is not only the absolute C6 value, but how much of the PSP-to-all-electron gap is closed by adding the EFT-core channel: 

closure = (C6_PSP+EFT - C6_PSP) / (C6_all-electron - C6_PSP)
Case C6 PSP C6 PSP + dipole C6 all-electron Delta C6 Closure Status
Mg q2 clean 638.6202 647.6079 647.5881 +8.9878 ~100% Clean, strongest current benchmark
Ca q2 adapted 1496.3122 1658.0317 2206.7588 +161.7194 22.8% Clean by shell overlap, but q2 pseudo + q10 basis mismatch
Kr q8 clean 66.3555 69.2771 134.6496 +2.9216 4.3% Clean negative/control case
Ca q10 deep core 1424.6731 1425.3086 2206.7588 +0.6355 0.08% Deep-core-only diagnostic

This comparison separates two questions. The direction asks whether the added channel moves C6 from PSP toward all-electron. The closure asks how much of that missing response is actually recovered. Mg q2 is the clean case where both are currently strongest: the large-core PSP omits 2s/2p response, the dipole correction restores it, and the final C6 essentially coincides with the all-electron PBE-TDDFT reference.

Ca q2 adapted is also in the right direction, but it is not a final basis benchmark because the run combines a q2 pseudopotential with a q10 UZH basis. It is useful as evidence that shallow semicore channels matter, but it should remain labeled as an adapted diagnostic until a matched q2 basis is available.

6. Headline Result

The clean Mg q2 benchmark is the strongest current evidence that the pipeline can identify and add a missing frozen-core/semicore response without shell double counting. 

Mg q2:
PSP baseline       = 638.6202
PSP + dipole EFT   = 647.6079
All-e PBE TDDFT    = 647.5881
Gap closed         = ~100%
Double counting    = clean

This should be reported as a benchmark loop using an unscreened l=1 MO dipole Wilson approximation, not as the final screened EFT-vdW functional.

In physical terms, the q2 Mg pseudopotential leaves only the 3s valence shell explicit. The missing 2s/2p response is then added back as explicit dipole channels. Because these shells are absent from the PSP valence space, the double-counting guard marks the result clean.

7. Current Limitations

  • No valence-screened interaction W_v yet.
  • No screened pairwise or log-determinant vdW energy yet.
  • Ca q2 adapted result uses q2 pseudo with q10 UZH basis; diagnostic only.
  • The l=1 dipole channel is currently an atomic MO approximation, not a fully derived finite-xi Wilson coefficient.
  • Radial shell-average route remains diagnostic only due to TRK overcounting.

8. Recommended Next Steps

  1. Promote Mg q2 into the formal benchmark section of the project docs.
  2. Search for a matched Ca or Sr q2 large-core basis to obtain a second strong clean benchmark.
  3. Derive the finite-xi l=1 EFT Wilson coefficient more rigorously.
  4. Implement a minimal model W_v screening only after the clean unscreened correction is stable.
  5. Only then move toward screened pairwise and many-body/log-RPA forms.
